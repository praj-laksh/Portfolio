# Prajwal Lakshminath — Quantitative Finance Portfolio

Responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js` and the `assets` folder together.
3. Open `index.html` in a browser, or run `python -m http.server 8000`.

## Included
- Professional portrait in `assets/prajwal-professional.png`
- Résumé download in `assets/Prajwal_Lakshminath_Resume.pdf`
- Responsive navigation, project sections, education, credentials and contact form

The charts are illustrative and are not live market data or investment performance. The contact form opens the visitor's email application; it does not submit to a server.
